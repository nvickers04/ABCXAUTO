## How a seat works

1. Work lives in GitHub issues under the parent crew ticket.
2. Code lands on a `crew/<seat>-*` branch, then a draft PR against `master`.
3. Acceptance is a pytest that names the lie it kills.
4. A seat may tighten a floor. It may not weaken one.
5. A seat may write `docs/` and `scripts/`. It may not teach Grok how to trade.
